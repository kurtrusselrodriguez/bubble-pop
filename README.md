# Bubble Pop

A camera-based hand-gesture balloon survival game.

Install the dependencies with `py -m pip install -r requirements.txt`, then
start the game with `py BUBBLEPOP` or `START_BUBBLEPOP.bat`.

See [XAMPP_SETUP.md](XAMPP_SETUP.md) for database configuration. Account data is
stored locally in `bubble_accounts.json`, which is intentionally excluded from
version control.
